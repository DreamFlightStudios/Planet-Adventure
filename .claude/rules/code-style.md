# Стиль кода C#

Применяется ко всем `.cs` файлам в проекте.

> **Не применяется к `Generated/`** — это машинный вывод Jenny, см. `generated-readonly.md`.

## Структура файла и класса

- **Namespace повторяет путь от папки** под `Assets/` (например, `_Project.Develop.Runtime.Gameplay.Features.Timer.Systems`). Префикс `_Project.` — обязателен.
- **Порядок членов класса**: Поля → Конструктор → Свойства → Методы.
- **Внутри каждого блока** — порядок по модификатору доступа: `public` → `protected` → `private`.
- **События** относятся к полям (выше всех остальных полей).
- **Модификаторы доступа писать всегда явно** — кроме членов интерфейса (там подразумевается `public`).

## Именование

- `camelCase` — локальные переменные, параметры (`canMerge`, `playerMoney`).
- `_camelCase` — `private` поля (`_coins`, `_animator`).
- `PascalCase` — `public` и `protected` поля (protected именуем как public, без подчёркивания), **свойства** (всегда), методы, классы, интерфейсы, структуры, enum, namespace.
- `UPPER_SNAKE_CASE` — `const` (любой модификатор доступа). Это **переопределяет** общий принцип «свойства и константы PascalCase» — в этом проекте константы выделяются капсом.
- `static readonly` и `readonly` поля — **не константы**, именуем по правилу полей (`PascalCase` для public, `_camelCase` для private).
- **Bool-методы**: `IsX` / `CanX` / `HasX` (`IsEmpty()`, `CanMerge()`). Избегаем `CheckX` — это размытое имя, в такие методы часто прокрадываются side-effects.
- **`bool TryX(...)`** — методы, которые могут не выполниться и возвращают флаг успеха (`TryBuild`).
- **Свойства-флаги** — по той же схеме: `IsEmpty`, `CanMerge`.
- **События** именуем в прошедшем времени (`Killed`, `Damaged`); хендлеры — `OnX` (`OnKilled`); иногда допустимо без `On`.
- **Существительные** — для классов, полей, свойств; **глаголы** — для методов.
- **Точные имена, без сокращений**. Имя должно отражать суть; экономия на длине ничего не даёт.
- **Множественное число для коллекций** (`coins` — список монет, `coin` — одна монета).
- **Без тавтологии**: `Character.Move()`, не `Character.CharacterMove()` (на сайте вызова уже видно `character.`).
- **Без размытых имён** (`GameManagerController`, `…Manager`, `…Helper`) — обычно класс можно назвать точнее, чтобы имя отражало ответственность.

## Форматирование

- **`[SerializeField] private`** — для инспектор-полей (см. `WalkingView._animator`).
- **Явные типы вместо `var`** — `foreach (GameEntity timer in _timers...)`, не `foreach (var timer in ...)`.
- **Не более одной пустой строки подряд** — двух и больше пустых строк не ставим.
- **Блоки `if` / `switch` / `for` / `while` отделяем пустой строкой** от соседнего кода — визуально выделяем структуру.
- **Проверка на `false`**: `if (x == false)`, **не** `if (!x)` — читается лучше, восклицательный знак легко не заметить.
- **Между `case` в `switch` — пустая строка** для читаемости.
- **Группируем код пустыми строками** между методами и логическими блоками — код не должен превращаться в кашу из плотных строк.

## Содержимое

- **Никаких магических чисел** — выноси в именованную `const` или поле, чтобы было понятно, за что отвечает значение. Допустим `0`, если из контекста однозначно понятно (например, проверка на пустоту коллекции).
- **Без вычислений в выводимом тексте** (`Debug.Log`, интерполяция строк) — в выводе ожидаем готовый результат, не операции.
- **Убирать дубляж**: повторяющиеся блоки кода → выносим в метод.

## Асинхронные методы

- **Тип возврата — `UniTask` / `UniTask<T>` / `UniTaskVoid`.** `Task` / `Task<T>` не используем (см. CLAUDE.md, раздел стека).
- **Суффикс `Async` в имени — обязателен** для любого метода, возвращающего `UniTask` / `UniTask<T>` / `UniTaskVoid`. Примеры из проекта: `StartAsync`, `LoadAsync`, `UnloadAsync`, `WarmupAssetsByLabelAsync`. Это касается и публичных, и приватных методов, и сигнатур в интерфейсах.
- **`UniTaskVoid` — только для fire-and-forget**, когда из контекста невозможно `await` (например, точка входа из `Start()` MonoBehaviour-а — см. `GameplayBootstrap.CustomSetup`). Имя — тоже с суффиксом `Async`.
- **`async void` — запрещён.** Единственное допустимое исключение — обработчик C#-event / UnityEvent, чья сигнатура жёстко требует `void`. В таком случае тело **обязано** быть в `try`/`catch`, иначе исключение проглотится без следа.
- **`CancellationToken` — последним параметром**, имя — `cancellationToken`. Если у метода есть необязательные параметры со значениями по умолчанию — токен идёт после них. Пробрасывай токен во все вложенные `*Async`-вызовы внутри метода.
